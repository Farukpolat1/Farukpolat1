## 🚀 Projects

**🪟 Veltix: Stok Takip & Satış Takip**
Inventory and sales tracking system, first built for a PVC window
manufacturer. Multi-tenant, role-based access (admin / warehouse /
sales), stock movement history, and email notifications. Deployed to
production.
*Rails 8 · PostgreSQL · Solid Queue · Docker · Sentry*

**⚡ Şarj Haritası**
EV charging station map for Turkey. Users report station malfunctions
in real time (Action Cable), and an LLM-powered assistant turns
natural-language queries like "fast chargers near me" into structured
search filters.
*Rails · PostgreSQL · Action Cable · LLM API*

**📐 pencere-app**
Parametric window quoting and drawing tool for the Turkish window
industry. Windows are drawn live as SVG from dimensions and profile
parameters, and prices are calculated automatically.
*Vue 3 · Vite · Pinia · Node.js · Fastify · PostgreSQL*
